# Camalot genre research: summary

Quick pass, 2026-11-16. Full lists with sources are in the six genre files beside this one. Real game names are for reference only; Camalot versions get their own names and look.

|---|---|---|---|---|

## Patterns across all six
- Every hook falls into the same few types: revive or continue, multiply the reward, starting boost, unlock a skin, skip a wait. One shared question system can serve all six games.
- Loot boxes and random prizes show up in four genres. Camalot replaces them with fixed rewards.
- Online "players" in .io games are often bots. Camalot runs offline, so every competitive game needs its own bots; no source describes how theirs behave.
